## Code

Transparent and documented code is crucial for scientific reproducibility and the understanding of complex concepts. Using [nbdev](https://nbdev.fast.ai/) and [quarto](https://quarto.org/), I strive to code models and run simulations in fully documented and reproducible environments. You can find my main repositories here:

* Collective Asymmetric Reinforcement Learning (CARL): an agent-based model of RL decision-makers with a confirmation bias. [Available [here](https://github.com/clembergerot/CARL)]
* Deterministic Distributional Reinforcement Learning (DDRL): a multi-agent RL model to simulate and visualize collective learning dynamics in Markov environments. [Available [here](https://github.com/clembergerot/pyDDRL)]
